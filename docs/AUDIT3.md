## Integrity rule for fixes that touch the model or the data

The 2024 held-out result was produced by code frozen before the 2024 data were downloaded. Any fix to the energy model or the data pipeline (issues 1 and 18) means the 2024 run can no longer be repeated under that claim. Therefore:
- The frozen 2024 verdicts stay the confirmatory result and are reported unchanged.
- The corrected models are run on both years and reported as a post hoc sensitivity analysis, labelled as such, with every verdict that changes stated.
- The frozen code and its hashes stay untouched (docs/CONFIRMATORY_FREEZE.txt).
